# v2 원격 witness 이관 검증

[이관 절차](../remote-witness-v2-migration.md) · [훈련 기록](remote-witness-v2-migration-2026-11-24/recovery-drill.json) · [회귀 테스트](../../analysis/remote-witness-migration.test.mjs)

- **원본 보존.** v2 승인 원문과 정책 데이터를 이관 전후 비교했다. 폐기된 profile, 제거된 domain의 anchor·하한, 검증된 메타데이터로 전진한 하한 및 기존 TUF 저장소 데이터가 유지됐다. 새 모드에서 낮은 버전을 거절하고 유효한 최신 TUF 갱신 후 인증을 재개했다.
- **재시도.** 원격 HTTPS 커밋 직후 실제 이관 프로세스를 종료했다. pending 동결은 살아 있었고 기존 스캔과 v2 복구는 거절됐다. 서버 재시작 뒤 일반 resume 명령으로 같은 원격 항목을 확정했다. 게시 전 응답 누락, 동시에 들어온 재시도, 다른 승인, 같은 순번 충돌, 손상된 로컬 상태도 확인했다.
- **리뷰 수정.** 승인에서 고정한 원격 설정인지 네트워크 호출 전에 확인해 승인되지 않은 endpoint로의 자격 증명 전송을 차단했다. 원격 쓰기 권한을 동결 이전에 검사하고, v2 복구를 우회 경로로 쓰지 못하도록 로컬 witness head도 동결 transaction에서 제거했다.
- **로컬 검증.** Node 24.22.3에서 전체 407개와 신규 이관 13개, CLI 훈련 4단계, 문서 98개가 통과했다.
- **검증 범위.** 임시 키, 테스트용 정책, HTTPS 서비스와 SQLite 저장소를 사용했다. 운영 조직·실제 운영 키·전원 장애를 검증하는 단계는 별도다. 테스트의 원격 서비스 저장소는 이관 프로세스와 별도로 유지됐다.
